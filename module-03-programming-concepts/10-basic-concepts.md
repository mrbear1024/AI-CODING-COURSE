# 第10章：编程基本概念 — 所有语言共通的"积木"

## 引言

不管你学的是中文还是英文，都绕不开名词、动词、句子结构这些基础。编程语言也一样——不管是 Python 还是 JavaScript，都建立在几个核心概念之上。

这一章的目标不是让你背语法，而是让你能**读懂 AI 生成的代码**。就像你不需要会写小说，但要能看懂一篇文章讲的是什么。

---

## 概念讲解

### 1. 变量（Variable）— 贴了标签的盒子

**变量**就是一个有名字的"盒子"，里面可以存放数据。

```python
name = "小明"        # 盒子叫 name，里面放了"小明"
age = 25             # 盒子叫 age，里面放了数字 25
is_student = True    # 盒子叫 is_student，里面放了"是"（True）
```

**类比**：想象你搬家时在纸箱上贴标签——"厨房用品""冬天衣服""书籍"。变量名就是标签，里面的东西就是数据。你可以随时打开盒子换掉里面的东西：

```python
age = 25      # 今年 25 岁
age = 26      # 过了生日，变成 26 岁了
```

### 2. 数据类型（Data Type）— 盒子里能放什么

不同的盒子装不同的东西，数据也有不同的"类型"：

| 数据类型 | 英文名 | 例子 | 类比 |
|---------|--------|------|------|
| 数字 | Number / Integer / Float | `42`、`3.14` | 计算器里的数 |
| 字符串 | String | `"你好世界"` | 一段文字，用引号包起来 |
| 布尔值 | Boolean | `True` / `False` | 开关——要么开，要么关 |
| 数组/列表 | Array / List | `["苹果", "香蕉", "橙子"]` | 购物清单——有序排列的一组东西 |
| 对象/字典 | Object / Dictionary | `{"name": "小明", "age": 25}` | 身份证——用"字段名:值"配对存信息 |

**类比**：数据类型就像容器的种类。你不会用水杯装米饭（类型不匹配），同样，程序里把数字和文字混着用也会出问题。

### 3. 条件判断（Conditional Statement）— 如果……就……

生活中我们时刻在做判断："如果下雨，就带伞；否则，穿短袖。"程序也一样：

```python
weather = "下雨"

if weather == "下雨":
    print("带伞出门")
elif weather == "大太阳":
    print("涂防晒霜")
else:
    print("正常出门")
```

- `if`：如果条件成立，执行这段代码
- `elif`（else if 的缩写）：否则如果另一个条件成立
- `else`：以上都不成立时，执行这段

**类比**：条件判断就像岔路口的路牌——根据当前情况，走不同的路。

### 4. 循环（Loop）— 重复做一件事

假如你要给班上 30 个同学每人发一条消息，你不会写 30 遍同样的代码，而是用循环：

```python
students = ["小明", "小红", "小刚", "小李"]

for student in students:
    print(f"你好，{student}！欢迎来上课。")
```

输出：
```
你好，小明！欢迎来上课。
你好，小红！欢迎来上课。
你好，小刚！欢迎来上课。
你好，小李！欢迎来上课。
```

**类比**：循环就像工厂流水线——同样的操作对每个产品重复执行一遍。你只需要定义一次"怎么做"，循环帮你对所有对象执行。

还有一种 `while` 循环——"只要条件成立，就一直做"：

```python
count = 0
while count < 5:
    print(f"这是第 {count + 1} 次")
    count = count + 1
```

**类比**：`while` 循环就像"直到吃饱为止，每次再吃一口"。

### 5. 函数（Function）— 可重复使用的"菜谱"

如果你经常需要做番茄炒蛋，你不会每次从头想步骤，而是写一份菜谱，以后照着做就行。函数就是这样的"菜谱"：

```python
def greet(name, time_of_day):
    """根据时间段打招呼"""
    if time_of_day == "早上":
        return f"早上好，{name}！"
    elif time_of_day == "晚上":
        return f"晚上好，{name}！"
    else:
        return f"你好，{name}！"

# 使用函数（"照着菜谱做"）
message = greet("小明", "早上")
print(message)   # 输出：早上好，小明！
```

- `def`：定义一个函数（写菜谱）
- `name` 和 `time_of_day`：**参数（Parameter）**——需要你提供的"食材"
- `return`：返回结果（端出成品菜）

**类比**：函数 = 菜谱。参数 = 食材。返回值 = 做好的菜。你写一次菜谱，可以用不同食材反复做。

---

## 类比总结：一张图看懂五大概念

想象你在经营一家餐厅：

- **变量** = 食材储物柜（贴好标签，随时取用）
- **数据类型** = 食材种类（蔬菜、肉类、调料，不能混乱存放）
- **条件判断** = 菜单上的备注（"如果顾客要辣，加辣椒；否则不加"）
- **循环** = 流水线出餐（同一道菜做 50 份，步骤一样）
- **函数** = 标准菜谱（写一次，全厨房都能用）

## 实操步骤

### 练习1：阅读理解——读懂一段真实代码

看看下面这段代码，试着用"大白话"说出它在做什么：

```python
prices = [15, 28, 42, 9, 33]
total = 0

for price in prices:
    if price > 20:
        total = total + price

print(f"超过20元的商品总价是：{total}元")
```

> 参考答案：有一组商品价格，程序遍历每个价格，如果超过 20 元就加到总价里，最后打印出总价。

### 练习2：找出"积木"

回到上面的代码，标注出：
- 哪些是**变量**？（`prices`、`total`、`price`）
- 哪里是**循环**？（`for price in prices:`）
- 哪里是**条件判断**？（`if price > 20:`）
- 用了哪些**数据类型**？（列表、数字、字符串）

## 本章小结

| 概念 | 一句话解释 | 核心类比 |
|------|-----------|---------|
| 变量（Variable） | 有名字的盒子，存放数据 | 贴标签的储物柜 |
| 数据类型（Data Type） | 数据的分类：数字、文字、真/假等 | 食材种类 |
| 条件判断（if/else） | 根据条件走不同的路 | 岔路口的路牌 |
| 循环（Loop） | 重复执行同一段操作 | 工厂流水线 |
| 函数（Function） | 封装好的可重复使用的代码块 | 标准菜谱 |

> **记住**：你的目标不是写出完美代码，而是能**读懂** AI 写的代码，判断它对不对、好不好。这就像你不需要会做菜，但要能看懂菜谱、尝出味道来。
