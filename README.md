# 使用 AI/LLM 构建自己的软件项目

> 一套面向零基础用户的 AI 编程课程 — 从完全不懂代码，到独立用 AI 构建并上线自己的软件项目。

## 这门课适合谁？

- 没有计算机专业背景，但对编程和 AI 感兴趣的人
- 想把自己的想法变成真实可运行软件的创业者、产品经理、设计师
- 想了解"AI 编程"到底能做什么的好奇者
- 任何想用 AI 提升工作效率、自动化日常任务的人

## 你不需要什么

- 不需要计算机科学学位
- 不需要会写代码
- 不需要数学很好
- 只需要一台电脑和学习的热情

## 如何使用本课程

1. **按顺序学习**：模块之间有递进关系，建议从模块一开始
2. **动手实操**：每章都有练习，一定要亲手做一遍
3. **善用 AI**：遇到不理解的地方，随时问 AI 帮你解释
4. **不要怕犯错**：编程就是不断试错的过程，AI 会帮你修复错误
