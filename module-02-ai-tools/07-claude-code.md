# 第7章：Claude Code — AI 命令行编程助手

## 概念讲解

在前两章中，我们了解了 LLM 的原理和如何写好 Prompt。但每次编程都要在浏览器和编辑器之间来回切换、复制粘贴代码，是不是有点麻烦？

**Claude Code** 就是为了解决这个问题而生的工具。它是 Anthropic 推出的**命令行 AI 编程助手**——直接在你的终端（Terminal）里运行，能够读取你的项目文件、帮你写代码、改代码、运行命令，全程不需要离开命令行。

## 类比说明：从"远程顾问"到"驻场工程师"

如果说在网页上使用 ChatGPT 或 Claude 聊天就像**打电话请教远程顾问**——你得把情况描述一遍，他给了建议你还得自己动手改——那么 Claude Code 就像请了一个**驻场工程师**，他直接坐在你的工位旁边，能看到你的电脑屏幕上的代码，你说一声"帮我把这个函数改一下"，他就直接上手帮你改了。

核心区别：

| 网页聊天（如 claude.ai） | Claude Code（命令行） |
|-------------------------|---------------------|
| 你手动复制粘贴代码 | 它直接读取你的项目文件 |
| AI 给出建议，你自己改 | AI 直接编辑你的文件 |
| 无法运行代码 | 可以帮你运行命令、跑测试 |
| 每次对话独立 | 始终了解项目上下文 |

## 实操步骤

### 第1步：安装 Claude Code

Claude Code 通过 npm（Node.js 的包管理器）安装。打开终端，输入：

```bash
# 确保已安装 Node.js（版本 18 或以上）
node --version

# 全局安装 Claude Code
npm install -g @anthropic-ai/claude-code
```

> 如果你还没有安装 Node.js，可以从 [nodejs.org](https://nodejs.org) 下载安装。这就像要用微信，你得先安装微信 App 一样。

### 第2步：配置 API Key

Claude Code 需要一个 **API Key（接口密钥）** 来连接 Anthropic 的服务器。这就像你用手机 App 需要登录账号一样。

```bash
# 启动 Claude Code，首次运行会引导你登录
claude
```

首次启动时，Claude Code 会引导你完成认证。你可以通过 Anthropic Console 获取 API Key，也可以直接使用 OAuth 登录。

### 第3步：开始使用

进入你的项目目录，启动 Claude Code：

```bash
# 进入项目文件夹
cd my-project

# 启动 Claude Code
claude
```

现在你就可以用自然语言和它对话了！

### 核心使用场景

**场景1：生成代码**
```
你> 帮我创建一个 Python 脚本，读取 data.csv 文件并统计每列的平均值
```
Claude Code 会直接在你的项目中创建文件并写入代码。

**场景2：理解代码**
```
你> 帮我解释 src/utils.py 这个文件里的每个函数都做了什么
```
它能直接读取你项目中的文件，不需要你复制粘贴。

**场景3：调试错误**
```
你> 我运行 python main.py 的时候报错了，帮我看看什么问题
```
它可以帮你运行命令、看到报错信息、然后定位并修复问题。

**场景4：重构代码（Refactoring）**
```
你> 把 app.py 里重复的数据库查询逻辑提取成一个单独的函数
```
它理解你的代码结构，直接帮你重构。

### 第4步：配置 CLAUDE.md 项目文件

在项目根目录创建一个 **CLAUDE.md** 文件，可以告诉 Claude Code 关于项目的重要信息。这就像给新来的同事写一份**项目交接文档**。

```markdown
# CLAUDE.md

## 项目概述
这是一个用 Python Flask 写的个人博客系统。

## 技术栈
- Python 3.11
- Flask 框架
- SQLite 数据库
- 前端用 HTML + Tailwind CSS

## 代码规范
- 使用中文注释
- 函数命名用 snake_case（下划线命名法）
- 每个函数都要有 docstring（文档字符串）

## 常用命令
- 启动开发服务器：python app.py
- 运行测试：pytest tests/
- 数据库迁移：python migrate.py
```

有了这个文件，Claude Code 每次启动都会读取它，从一开始就了解你的项目背景和偏好。

## 实用工作流示例

### 工作流1：从零创建一个新项目

```
你> 帮我创建一个 Python 命令行待办事项程序，
    支持添加、删除、查看和标记完成，
    数据保存在 JSON 文件里
```

Claude Code 会：
1. 创建项目文件结构
2. 编写主程序代码
3. 添加数据持久化逻辑
4. 甚至可以帮你运行测试

### 工作流2：修复一个 Bug

```
你> 运行 python app.py 然后告诉我发生了什么

[Claude Code 运行命令，看到报错]

你> 帮我修复这个错误

[Claude Code 定位问题文件，修改代码]

你> 再运行一次看看修好了没有

[Claude Code 再次运行，确认修复成功]
```

### 工作流3：日常编程助手

```
你> 这段代码能不能写得更简洁？看一下 src/helpers.py 第30-50行
你> 帮我给所有函数添加类型注解（Type Hints）
你> 生成这个模块的单元测试（Unit Test）
```

## Tips 和最佳实践

1. **具体描述需求**：和第6章学的 Prompt 技巧一样，描述越具体，结果越好。

2. **善用 CLAUDE.md**：把项目的关键信息写在 CLAUDE.md 中，避免每次重复说明。

3. **分步推进**：不要一次要求太多，复杂任务拆成小步骤。就像盖房子——先打地基，再砌墙，最后装修。

4. **检查生成的代码**：Claude Code 很强大，但它生成的代码你一定要**看懂再用**。不理解的代码就让它解释。

5. **利用对话上下文**：一次会话中，Claude Code 记得之前的对话内容，所以你可以逐步深入，不必每次重复背景信息。

6. **快捷命令**：
   - 输入 `/help` 查看帮助
   - 输入 `/clear` 清除对话历史
   - 输入 `/cost` 查看本次会话消耗的 Token 和费用

## AI 辅助练习

1. **安装体验**：按照上面的步骤安装 Claude Code，然后启动它，输入"你好，请介绍一下你能做什么"。感受命令行 AI 的交互方式。

2. **创建小项目**：让 Claude Code 帮你创建一个简单的 Python 计算器程序。观察它是如何创建文件、写入代码的。

3. **调试练习**：故意在某个 Python 文件中引入一个拼写错误，然后让 Claude Code 帮你找到并修复它。

4. **CLAUDE.md 实践**：为你正在学习的某个项目写一份 CLAUDE.md 文件。即使内容很简单（项目是做什么的、用了什么技术），这也是好的开始。
