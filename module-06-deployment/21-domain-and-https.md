# 第21章：域名与 HTTPS

## 概念讲解

### 什么是域名（Domain Name）？

每台连接到互联网的电脑都有一个**IP 地址（IP Address）**，比如 `93.184.216.34`。这就像每栋房子都有经纬度坐标一样——精确，但没人记得住。

**域名就是给 IP 地址取的"昵称"**。比起记住 `142.250.80.46`，记住 `google.com` 就容易多了吧？

再打个比方：IP 地址是你家的 GPS 坐标，域名是你家的门牌地址"幸福路 88 号"。两者指向同一个地方，但地址显然更好记。

### 如何购买域名

购买域名就像注册一个独一无二的名字。常用的**域名注册商（Domain Registrar）**有：

- **Cloudflare Registrar**：价格透明，无加价（推荐）
- **Namecheap**：便宜，界面友好
- **GoDaddy**：最大的注册商，但续费较贵
- **阿里云万网**：国内首选，支持 `.cn` 域名

购买流程非常简单：
1. 去注册商网站搜索你想要的域名
2. 如果没被人注册，加入购物车
3. 付费（通常 `.com` 域名每年约 50-100 元人民币）
4. 域名就是你的了！

> 小贴士：`.com` 是最通用的后缀，`.dev` 适合开发者项目，`.cn` 适合面向中国的网站。

### DNS：互联网的"电话簿"

**DNS（Domain Name System，域名系统）**是互联网最重要的基础设施之一。它的工作就是把域名翻译成 IP 地址。

想象一下：你跟朋友说"我们去星巴克"。你的手机打开地图 App，搜索"星巴克"，地图返回一个具体地址。DNS 做的事情一模一样——你在浏览器输入 `example.com`，DNS 帮你找到对应的服务器 IP 地址。

**DNS 解析过程**（简化版）：

```
你输入 example.com
    ↓
浏览器问 DNS 服务器："example.com 的 IP 是什么？"
    ↓
DNS 服务器查找后回答："是 93.184.216.34"
    ↓
浏览器连接到 93.184.216.34
    ↓
网页显示出来！
```

### DNS 记录类型

DNS 记录就像电话簿里不同类型的联系方式。最常用的有三种：

**A 记录（Address Record）**
最基本的记录，直接把域名指向一个 IP 地址。
```
example.com  →  93.184.216.34
```
类比：就像电话簿里写着"张三 → 138xxxxxxxx"。

**CNAME 记录（Canonical Name Record）**
把一个域名指向另一个域名（起别名）。
```
www.example.com  →  example.com
blog.example.com →  my-blog.vercel.app
```
类比：就像电话簿里写着"张三的办公室电话 → 同张三手机号"。

**MX 记录（Mail Exchange Record）**
告诉互联网你的邮件由哪个服务器处理。
```
example.com  →  mail.example.com（邮件服务器）
```
类比：就像告诉邮局"寄到幸福路 88 号的信，请送到旁边的收发室"。

### SSL 证书与 HTTPS：浏览器里的小锁头

你有没有注意过浏览器地址栏里的那个**小锁头图标**？它表示这个网站使用了 **HTTPS（HyperText Transfer Protocol Secure）**，你的数据传输是加密的。

**HTTP vs HTTPS 的区别**：

想象你在咖啡馆给朋友传纸条。
- **HTTP** 就像明文纸条——任何经手的人都能偷看内容
- **HTTPS** 就像把纸条锁在一个只有你和朋友能打开的小盒子里——中间人看不懂

HTTPS 的核心是 **SSL/TLS 证书（SSL Certificate）**。它做两件事：
1. **加密数据传输**：别人截获了也看不懂
2. **验证身份**：确认你访问的确实是真正的网站，不是冒牌货

### Let's Encrypt：免费的 SSL 证书

过去，SSL 证书要花钱买，一年几百甚至上千元。但 **Let's Encrypt** 改变了这一切——它是一个**免费的证书颁发机构（Certificate Authority, CA）**，让所有网站都能免费用上 HTTPS。

好消息是：如果你使用 Vercel、Netlify、Cloudflare 等平台，**它们会自动帮你配置 SSL 证书**，你完全不用操心。

## 实操步骤

### 动手实践：为你的项目配置自定义域名

以 Vercel + Cloudflare 为例：

**第一步：购买域名**
1. 访问 [cloudflare.com](https://cloudflare.com)，注册并登录
2. 在 "Domain Registration" 中搜索你想要的域名
3. 完成购买

**第二步：在 Vercel 中添加域名**
1. 进入你的 Vercel 项目 → Settings → Domains
2. 输入你购买的域名，比如 `myproject.com`
3. Vercel 会告诉你需要添加什么 DNS 记录

**第三步：配置 DNS 记录**
1. 回到 Cloudflare 控制台
2. 进入你域名的 DNS 设置
3. 按照 Vercel 的提示添加记录，通常是：
   - 类型：`A`，名称：`@`，值：`76.76.21.21`
   - 类型：`CNAME`，名称：`www`，值：`cname.vercel-dns.com`

**第四步：等待生效**
DNS 记录需要时间传播，通常几分钟到几小时不等。生效后，你就可以通过自定义域名访问你的网站了！Vercel 会自动配置 SSL 证书。

```
配置前：myproject.vercel.app
配置后：myproject.com ✨（带 HTTPS 小锁头）
```

## 本章小结

- **域名（Domain）**是 IP 地址的"昵称"，让人更容易记住网站地址
- 推荐通过 **Cloudflare** 或 **Namecheap** 购买域名
- **DNS** 是互联网的"电话簿"，把域名翻译成 IP 地址
- 常用 DNS 记录：**A 记录**（指向 IP）、**CNAME**（指向另一个域名）、**MX**（邮件服务器）
- **HTTPS** 加密你的数据传输，浏览器里的小锁头就是标志
- **Let's Encrypt** 提供免费 SSL 证书；Vercel/Netlify 等平台会自动配置
- 配置域名的核心步骤：**买域名 → 添加 DNS 记录 → 等待生效**
