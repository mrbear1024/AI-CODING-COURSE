# 第2章：计算机基础常识

## 引言

在正式写代码之前，我们需要先了解一下你每天都在用的电脑到底是怎么工作的。

别担心，这一章不会有复杂的电路图或数学公式。我们会用日常生活中的比喻来解释一切。学完这章，你会对"程序是怎么跑起来的"有一个清晰的画面。

---

## 2.1 计算机的核心部件

### CPU——大脑

CPU（Central Processing Unit，中央处理器）是计算机的"大脑"。它负责**执行指令**——就是做计算、做判断、处理数据。

打个比方：CPU 就像一个厨师。你给他菜谱（程序），他就按照步骤一步一步地做菜（执行指令）。厨师的手速越快，做菜就越快——这就是为什么我们说 CPU 的"频率"越高，电脑越快。

### 内存（RAM）——工作台

RAM（Random Access Memory，随机存取存储器）是计算机的"工作台"。CPU 做计算的时候，需要一个地方临时放东西——这个地方就是内存。

类比：厨师（CPU）做菜时，食材和调料都摆在工作台（RAM）上，随手就能拿到。工作台越大，能同时处理的食材就越多，做菜效率就越高。但是——工作台上的东西在你关机（收工）后就会被清空。

### 硬盘——储物柜

硬盘（Hard Drive / SSD）是长期存储数据的地方。你的照片、文档、软件都存在硬盘里。

类比：硬盘就像厨房的储物柜。食材平时都放在柜子里，需要用的时候再拿到工作台上。储物柜里的东西不会因为关机而消失。

### 一句话总结

> CPU 是厨师，RAM 是工作台，硬盘是储物柜。厨师从储物柜取食材放到工作台上，按菜谱做菜。

## 2.2 什么是操作系统？

操作系统（Operating System，简称 OS）是管理你电脑所有硬件和软件的"大管家"。

常见的操作系统有三种：
- **Windows**——微软出品，大部分办公电脑在用
- **macOS**——苹果电脑专用
- **Linux**——开源免费，程序员和服务器最爱

### 类比：操作系统是大楼物业

想象你的电脑是一栋大楼：

- **硬件**（CPU、内存、硬盘）是大楼的基础设施——水管、电线、电梯
- **操作系统**是物业管理公司——它负责协调一切：谁能用电梯、水电怎么分配、垃圾怎么处理
- **应用程序（Application）**是住在楼里的住户——浏览器、微信、音乐播放器

没有物业（OS），住户（App）就没法正常使用大楼的设施（硬件）。所以当你打开微信时，实际上是操作系统帮你调用了屏幕、网络、扬声器等硬件资源。

## 2.3 什么是文件系统？

文件系统（File System）是操作系统用来**组织和管理文件**的方式。

### 类比：文件柜

想象一个巨大的文件柜：
- **文件柜**本身 = 你的硬盘
- **抽屉** = 大的文件夹（Folder / Directory）
- **文件夹里的分隔板** = 子文件夹（Subfolder）
- **纸张** = 文件（File）

在电脑里，文件是按照**树形结构（Tree Structure）**组织的。最顶层叫"根目录（Root Directory）"：

```
Windows: C:\
macOS / Linux: /
```

往下展开就是层层嵌套的文件夹：

```
/
├── Users/
│   └── xiaoming/
│       ├── Documents/
│       │   └── report.docx
│       ├── Pictures/
│       │   └── photo.jpg
│       └── Desktop/
├── Applications/
└── System/
```

每个文件都有一个唯一的"地址"，叫做**路径（Path）**。比如 `C:\Users\xiaoming\Documents\report.docx` 就是一个路径——它精确地告诉电脑这个文件在哪里。

## 2.4 什么是"程序"？

程序（Program）说白了就是**一组指令的集合**，告诉电脑该做什么。

### 类比：菜谱

一个程序就像一本菜谱：

```
菜谱：西红柿炒蛋
1. 打两个鸡蛋，搅拌均匀
2. 西红柿切块
3. 热锅，倒油
4. 先炒鸡蛋，盛出
5. 再炒西红柿
6. 把鸡蛋倒回去，翻炒
7. 加盐，出锅
```

程序就是给 CPU 的"菜谱"。只不过它用的不是中文，而是**编程语言（Programming Language）**——比如 Python、JavaScript 等。

### 代码是怎么变成可运行的程序的？

这个过程大致分三步：

1. **编写代码（Write Code）**——程序员（或 AI！）用编程语言写出指令
2. **翻译（Compile / Interpret）**——电脑不懂 Python，它只懂二进制（Binary），所以需要一个"翻译官"把代码翻译成机器能理解的语言
3. **执行（Execute）**——CPU 按照翻译后的指令一步步执行

这个"翻译官"对于不同语言有不同的名字：
- **编译器（Compiler）**——一次性把整本菜谱翻译好，再去做菜（C、Java 等语言用这种方式）
- **解释器（Interpreter）**——翻译一句，做一步（Python、JavaScript 等语言用这种方式）

## 2.5 什么是二进制？

你可能听过"计算机只懂 0 和 1"——这是真的。

我们人类用**十进制（Decimal）**，有 0-9 十个数字。计算机用**二进制（Binary）**，只有 0 和 1 两个数字。

为什么？因为电脑的底层是电路，电路只有两种状态：**通电（1）和断电（0）**。就像一个灯泡，要么亮（1），要么灭（0）。

你不需要学会二进制计算，只要知道一件事：**你写的任何代码、你存的任何文件，最终在电脑里都是一串 0 和 1**。编程语言的作用就是让你不用直接跟 0 和 1 打交道——就像你用中文点菜，服务员帮你翻译给厨师。

## 2.6 什么是终端？

终端（Terminal）是你跟操作系统"对话"的一个窗口。跟点击图标、拖动窗口不同，在终端里你**用文字输入命令**。

### 类比：微信聊天 vs. 面对面比划

平时你操作电脑，是通过**图形界面（GUI, Graphical User Interface）**——点点鼠标、拖拖窗口。这就像面对面比划，直观但效率有限。

终端则是**命令行界面（CLI, Command Line Interface）**——你打字告诉电脑该做什么。这就像发微信，虽然没有画面，但**表达更精确、更高效**。

程序员为什么爱用终端？因为很多操作用命令行只需要一行字，而用图形界面可能需要点击十几次。我们下一章就会详细学习命令行的使用！

## 2.7 实践练习

### 练习 1：查看你电脑的配置

- **Windows**：右键"此电脑" → "属性"，查看 CPU 型号和内存大小
- **macOS**：点左上角苹果图标 → "关于本机"

试着找到你的 CPU 名称、内存（RAM）大小、硬盘容量。

### 练习 2：浏览文件系统

打开你电脑的文件管理器（Windows 的"文件资源管理器"或 macOS 的"访达"），从根目录开始逐层浏览，体会"树形结构"。

### 练习 3：问 AI 一个问题

向 AI 提问：

> 请用最简单的比喻解释：CPU、内存和硬盘分别是什么？它们怎么协同工作？

把 AI 的回答和本章的解释对比一下，看看哪个你更容易理解。
